# Ryan's Claude Code Plugins

A personal marketplace of Claude Code plugins.

## Plugins

| Plugin | Description |
|--------|-------------|
| [yt-summarizer](https://github.com/ryanlewis/claude-summarize-youtube) | Summarize YouTube videos from transcripts |

## Installation

Install any plugin from this marketplace:

```
/plugin install <plugin-name>@github.com/ryanlewis/claude-plugins
```

For example:
```
/plugin install yt-summarizer@github.com/ryanlewis/claude-plugins
```

## Adding This Marketplace

You can add this marketplace to your Claude Code installation to browse and install plugins:

```
/plugin marketplace add github.com/ryanlewis/claude-plugins
```
